Challenge walkthrough (Box2)

Image build:
- docker build -t hack-box2 .

Run container (shell override) or SSH:
- docker run -it --entrypoint /bin/bash hack-box2
- or: docker run -d -p 2222:22 hack-box2 && ssh hackRCC2@localhost -p 2222 (password: hackRCC2)

Prep hashes:
- unshadow /etc/passwd /etc/shadow > hashes.txt
