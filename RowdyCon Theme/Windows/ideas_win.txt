Box 3:
Mission 3: Persistence Detected
Concept: file discovery/filtering, file movement, scheduled tasks (persistence/defense evasion), troubleshooting
The Scenario: Inside a directory named Evidence, there are many files. Only one is larger than 10 MB — that’s the payload you must exfiltrate. You create an Exfiltrate folder as your drop location, but a hostile Scheduled Task is constantly deleting anything placed inside it.

The User's Task:
1. Enumerate the files in Evidence and identify the one larger than 10 MB.
2. Create a folder named Exfiltrate.
3. Attempt to move the large file into Exfiltrate — notice it disappears.
4. List scheduled tasks and identify the one responsible for wiping Exfiltrate.
5. Delete (or disable) the wiping task.
6. Move the large file into Exfiltrate again.
7. A second scheduled task detects the file and prints the flag in the console.

Expected Solution Path (Example)

Find the 672 KB file: fad2v0be-5p0b-29c8-bh60-1f82ccb94abb.bin

Get-ChildItem .\Evidence | Where-Object { $_.Length -gt 672KB }


Create the drop folder:

New-Item -ItemType Directory .\Exfiltrate


Try the move (it will get wiped):

Move-Item .\Evidence\<BIGFILE> .\Exfiltrate\


Find the wiping scheduled task (example search patterns):

Get-ScheduledTask


Disable it (safe option):

Disable-ScheduledTask -TaskName "<WIPER_TASK_NAME>"


OR remove it (hard shutdown):

Unregister-ScheduledTask -TaskName "<WIPER_TASK_NAME>" -Confirm:$false


Move the file again:

Move-Item .\Evidence\<BIGFILE> .\Exfiltrate\


Confirm it stays:

Get-ChildItem .\Exfiltrate
